# Changesets

Здесь копятся описания изменений до выпуска версии.

```bash
npx changeset          # описать изменение: patch / minor / major и текст для журнала
npx changeset version  # собрать описания: поднять версию в package.json и дописать CHANGELOG.md
```

Подробно — в [docs/09-publishing.md](../docs/09-publishing.md).
