## Как учиться на этом проекте

1. **Запустите Storybook** (`npm run dev`) и пройдите каждый компонент **без мыши**: Tab,
   стрелки, Enter, Пробел, Escape. Потом откройте его исходник и найдите, где это написано.
2. **Включите скринридер** хотя бы раз: на Mac — `Cmd + F5` (VoiceOver). Откройте диалог, меню,
   селект и послушайте, что он говорит. Это лучший способ понять главу 05.
3. **Читайте в таком порядке:** `primitives/compose.ts` → `slot.tsx` → `components/button` →
   `field` → `checkbox` → `tabs` → `primitives/layers.ts` → `focus.ts` → `dialog` →
   `position.ts` → `menu` → `select` → `toast`. От простого к сложному.
4. **Тесты — это список требований.** Откройте `dialog.test.tsx` и прочитайте только строки `it(…)`.
5. **Сломайте и почините:**
   - уберите `useInertOthers` из диалога — какой тест упадёт? а что изменится для скринридера?
   - поменяйте порядок `useInertOthers` и `useFocusTrap` — тесты скажут почему нельзя;
   - замените в `Checkbox` настоящий `<input>` на `<div role="checkbox">` и почините всё, что отвалилось;
   - добавьте компонент: `Slider`, `Combobox` с поиском или `DatePicker` — по шаблону из
     [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/);
   - добавьте подменю в `Menu` (стрелка вправо открывает, влево закрывает).
6. `npm run check` — линтер, типы, 133 теста, сборка, бюджет размера и проверка пакета.
