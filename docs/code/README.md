# Разбор кода: файл за файлом

Главы учебника объясняют **идеи**: доступность, слои, API. Здесь — **конкретный код**:
примитивы и компоненты «Опоры» разобраны порциями, после каждой — что она делает и зачем.

## Как устроена каждая страница

1. **Где это** — что видит и делает человек.
2. **Что делает** — по пунктам, человеческим языком.
3. **Пропсы и пример** — как пользоваться.
4. **Код по частям** — настоящий код с объяснением.
5. **Что будет, если…** — уберите строку и посмотрите, что сломается.
6. **Проверьте себя** — вопросы с ответами.
